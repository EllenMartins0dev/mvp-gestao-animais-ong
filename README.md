# MVP — Gestão de Animais | ONG Vira Lata 

## Sobre o projeto
Este projeto consiste no desenvolvimento de um Produto Mínimo Viável (MVP) para apoiar a organização das informações dos animais acolhidos pela ONG Vira Lata Vira Vida, localizada em Piracicaba-SP.

## Problema identificado
A dispersão dos registros pode dificultar a consulta e a atualização das informações dos animais, incluindo seu histórico de cuidados e sua situação de adoção, gerando retrabalho e dificultando a continuidade do acompanhamento.

## Objetivo
Desenvolver uma aplicação web que permita organizar e consultar os dados dos animais, registrar informações relevantes sobre seus cuidados e acompanhar sua situação no processo de adoção.

## Tecnologias previstas
- Python
- Django
- HTML e CSS
- Banco de dados relacional
- Git e GitHub para versionamento
- Testes automatizados
- GitHub Actions para Integração Contínua

## Escopo do MVP
O escopo inicial contempla o cadastro e a consulta dos animais, o registro de cuidados e o acompanhamento da situação de adoção. As funcionalidades serão implementadas progressivamente e avaliadas conforme os requisitos definidos.

## Status
Projeto acadêmico em desenvolvimento. As funcionalidades serão descritas como concluídas somente após sua implementação e verificação.

## Como executar
As instruções de instalação e execução serão adicionadas após a configuração do ambiente e das dependências do projeto.
